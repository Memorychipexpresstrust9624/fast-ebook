## 🛠 Troubleshooting Common Issues

If the software fails to open, verify your Windows version. The app requires a 64-bit operating system. Check that your user account has permission to install applications.

If a book fails to load, verify the file extension is .epub. This software supports standard files. If a file is corrupted, delete it and add a new copy.

The settings menu provides a "Clear Cache" option. Use this if the app starts to feel sluggish. This resets the temporary index files but preserves your book library.
